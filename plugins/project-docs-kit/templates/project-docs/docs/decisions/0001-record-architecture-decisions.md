# 0001. 중요 결정은 ADR로 기록한다

> 상태: 채택 · 날짜: <YYYY-MM-DD>

## 맥락
5명 규모에서 빠르게 움직이다 보면 "왜 이렇게 했는지"가 몇 달 뒤 증발한다.
사람이 바뀌면 더 심하다.

## 결정
되돌리기 어렵거나 논쟁이 있었던 결정은 `docs/decisions/`에 한 장씩 남긴다.
- 번호순 파일명(`0002-...`), 짧게(10~20줄), 결정 후 **수정하지 않고** 새 ADR로 덮는다.
- 회의에서 정해지면 그 자리에서 누군가 `template.md`를 복사해 쓴다.

## 결과
- 좋은 점: 의사결정 이력이 남아 온보딩·재검토가 쉬워진다.
- 비용: 결정마다 몇 분. 사소한 건 안 써도 된다(되돌리기 쉬우면 생략).
